## 使用

构建并在 Chrome 重新加载现有扩展，然后刷新阅读网页。第一次开启会先显示阅读设置；确认前不发送分析请求。滑块预览非当前段落变暗，默认保留原版 `.55` 不透明度，可以调到 `.08`（变暗92%）。设置中的预览是本地示例，不上传页面。

确认后，意群继续采用原来的整篇准备方式。等待结果时保留普通网页阅读；准备完成后悬浮只切换本地聚焦与高亮，不按段落创建 WorkOS 会话。

准备卡常态只展示阶段和已等待时间，不显示百分比、段落数量或常驻说明。时间来自当前分析任务的创建时间，退出重入后继续计时，显式重试使用新任务起点；等待超过30秒才补充后台继续说明。“退出”只关闭阅读界面，“停止”位于更多菜单中，连接不支持远端停止时明确提示继续等待结果。失败或状态不明时显示必要说明，详情按需展开；只有已确认失败/停止才允许重试。错误卡的更多菜单可选“继续阅读”，恢复工具条和独立的搭配功能。

实际收到进行中的任务后只扫描一次，成功后显示约1.5秒的就绪提示，再轻量过渡到工具条。缓存恢复不重放扫描、不强制等待；用户偏好减少动态效果时不播放旋转和进入退出动画。动画与计时器都只属于本地显示，退出或脚本销毁后清理，不停止后台任务。

阅读中的工具条只展示状态、图例、搭配、设置与退出。准备卡和工具条均根据网页主要文字明暗匹配主题。说明、设置和清单按需展开。

- **完整意群**：显示所有已验证意群。
- **仅显示骨架**：只显示 `isCore:true` 的片段；兼容旧结果时按蓝色核心解释。
- **原文练习**：隐藏意群背景，保留段落聚焦。固定搭配下划线仍由独立开关控制，想完全去除标记时也可关闭下划线。

首次默认不自动扫描固定搭配。打开“搭配”并点击扫描，可取得“文章表达”清单。条目默认折叠，只显示表达、简短含义、类别和已验证的出现次数，技术术语排在通用表达后面。展开一条后显示代表性原句、可选用法，以及一套“上一处／下一处、当前位置／总数”和一个“收藏表达”。原文下划线点击直接展开对应表达详情；位于原有链接/控件中的表达不会抢占原网页点击。

清单默认选较短、完整的原句；用户可通过位置导航选择另一例句后收藏。同一篇文章的同一规范化表达只保存一张表达卡，跨标签页同时收藏也由后台事务和唯一键保证；重复收藏不替换已存例句、释义或手动清空字段。重开清单会重新查询后台状态，反映删除或恢复。原有按原句收藏的普通词卡保留，不自动合并或改写历史卡片。

词卡分别保存学习名称（如 `protect … from …`）和原文实例，例句高亮仍严格对应实际英文，词卡标题与目录展示学习名称。“更多翻译”复用原查词弹窗；有文章分析释义时立即展示，不自动请求额外词典或翻译服务，来源也不伪装成词典或手工输入。

## 分析与原文

意群版本保留 `page-reading-v4`。每组分别保存语义和是否为核心：陈述、定义、适用范围、触发条件、原因、目的、结果、转折、让步、例外、举例、判断标准、背景、补充说明。前端确定性映射成原有四色，不接受模型提供样式：核心蓝色；非核心条件/范围紫色；原因/目的绿色；其他关系橙色。

鼠标停留320毫秒后显示简短阅读提示，如 `even if · 即使……也……`；普通核心陈述不默认弹说明。新结果可选返回 `cue`（原文内2–8词的准确表达及80字符内中文含义）和 `learningNote`（240字符内、有本句依据的关系说明）。具体说明需点击后查看，没有内容时不编写。旧缓存的抽象 `explanation` 不再直接展示，已知连接表达可用有限静态短义；不从连接词猜测具体主结论。

提示词区分范围与展示位置、真正触发与“即使……仍然……”的让步，保持必要补语、否定、并列和稀疏选择。不确定时允许空结果。定义、结果或判断标准不因语义类别而自动成为骨架，核心信息由独立布尔属性决定。

固定搭配版本为 `page-expressions-v1`，独立整篇任务。模型返回值得积累的固定表达、动词短语、搭配、句型和术语，含中文含义以及段落编号、原文片段和出现序号。本地从原文算 UTF-16 位置与例句，不使用生成例句或近似匹配。表达与意群可以交叠，两套 Highlight registry 独立清理。

学习名称允许有限的省略号模板，实际出现片段仍要求具体、连续、准确的原文。可选 `usage` 是短用法提示，不能视为程序已经证明语义正确。两类分析版本这次都不提高，避免界面更新触发旧文章重新分析；旧缓存立即获得折叠清单和简提示，新模板/具体学习说明只随未来的实际分析补充，不自动重跑补齐。

表达上限60条、300处出现；每条最多16个空格分隔词、240字符，含义200字符。收藏校验受限支持英文表达与技术数字/标点（如 HTTP 429、GPT-4、C++、Node.js），拒绝 HTML、URL、多段文本及超长内容。不是所有自然语言长句型都能保存，超出支持范围的片段不会强行显示。词边界检查防止把 `in` 定位到 `within`、把 `GPT` 定位到 `GPT-4`。

## 请求、缓存与失败

两类分析复用原后台生命周期和 IndexedDB meta 存储，缓存标识均含页面身份、完整阅读块及顺序、目标平台/Agent、分析类型与版本。更改颜色、聚焦强度、显示模式或下划线不会创建新任务。手动扫描和自动扫描使用同一表达缓存；同内容重复开启复用在途或完成结果。

旧记录缺少 mode 时视为意群；旧的未知状态意群仍阻止同模式跨版本重发，但不会阻止独立的搭配扫描。最多两个在途文章任务的原限制保留。退出只关闭网页效果，已提交任务继续后台保存；意群和搭配分别提供停止入口。未知状态不自动重试，明确失败或停止才提供用户手动重试。

一处非法表达定位不会破坏其他有效条目；非空返回全部无效则记为失败，允许手动重试。合法空数组表示没有选出表达，可成功缓存。意群失败仍支持聚焦，搭配失败不影响意群。正文变化时立即移除失配标记，重新进入后按新原文准备，不自动上传其他页面内容。

本地偏好通过后台的专用 get/set 消息读取和保存，只返回经过字段验证的显示设置。保留扩展现有 `TRUSTED_CONTEXTS` 存储限制，不向 Content Script 开放其他配置或凭据。首次设置保存中取消、导航或脚本失效后，不会在保存完成后启动分析。
