# v0.5 本地资产备份与迁移验收标准

## 目标

把会话和阅读卡片从“绑定某个 Chrome 扩展 ID 的内部数据”升级为用户可控制、可迁移、可读出的本地知识资产。v0.5.0 完成机器备份、安全恢复和 Markdown 出口，不接入云同步。

## 范围与安全边界

- 机器备份包含会话、消息、来源、Agent 产物元数据和阅读卡片五类 IndexedDB 实体。
- 不包含 WorkOS Token、User UUID、Organization UUID、扩展配置、数据库 `meta`、当前工作页和其他临时界面状态。
- 不包含上传文件二进制、网页正文快照、内部会话交接文本、原始 SSE 事件或 `blob:` / `data:` 临时地址。
- Agent 产物只保留文件名、类型、状态、大小和原有 HTTP(S) 链接，不下载或嵌入远端文件。
- 导入不修改连接凭据、Agent 配置和界面偏好；不访问网络，不新增 Chrome 权限。

## v0.5a：完整本地备份

- [x] 使用 `format: yemai-backup`、`formatVersion: 1` 的版本化数据契约。
- [x] 五张实体表在同一个只读事务中形成一致快照，并按稳定主键排序。
- [x] 设置页展示会话、消息、来源、产物、阅读卡片数量和上次导出时间。
- [x] 导出前冲刷当前内存工作区，完成后下载带 UTC 时间的 `.yemai.json` 文件。
- [x] 自动化扫描证明数据库 `meta` 中的凭据、临时 URL 和运行时字段不会进入备份。
- [x] 80 个会话、2,000 条消息可以完整导出且数量不丢失。

## v0.5b：安全导入

- [x] 文件超过 50 MB、JSON 损坏、格式错误或未知版本时，在数据库写入前拒绝。
- [x] 写入前检查实体必填字段、重复 ID、声明数量和消息/来源/产物引用关系。
- [x] 支持仅含图片或文件产物的回答与阅读卡片：`content` / `bodyMarkdown` 可以为空字符串，但不能缺失或使用错误类型。
- [x] 支持尚未绑定网页的占位来源：`url` 可以为空字符串，但不能缺失或使用错误类型。
- [x] 预览显示文件名、来源应用版本、导出时间和核心资产数量。
- [x] 默认合并；会话、消息、来源和产物以稳定主键去重，阅读卡片保留较新的 `updatedAt`。
- [x] 同一备份重复导入不产生重复实体。
- [x] “替换全部本地知识”必须二次确认，并明确说明不影响连接凭据与设置。
- [x] 五张表在一个读写事务中写入；任一表失败时全部回滚，成功后回读数量并重新加载工作区。
- [x] 原会话缺失的阅读卡片仍允许独立导入和阅读。

## v0.5c：阅读卡片可读导出

- [x] 单张卡片导出 Markdown，保留标题、正文、来源、收藏时间和安全产物链接。
- [x] 全部卡片合并导出为一个 Markdown 文件。
- [x] 非 HTTP(S) 链接不写入 Markdown；非法文件名字符、尾部点空格和 Windows 保留名会被规范化。
- [x] 同名下载由 Chrome 使用系统下载规则自动追加序号，不覆盖已有文件。
