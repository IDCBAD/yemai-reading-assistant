# v0.4.1 搜索生命周期与发布收口验收标准

## 目标

v0.4.1 不新增新的知识资产类型，而是收紧 v0.4 的运行与发布质量：让全局搜索只在用户需要时工作，让低频界面不占用首屏分包，并让开发版与正式版在 Chrome 扩展页中可以直接区分。

## 范围边界

- 本版本只处理搜索索引生命周期、搜索与阅读卡片界面的按需加载、开发构建标识、版本与发布文档。
- 不在本分支实现导出、导入、备份、云同步或数据格式迁移；这些能力留给 v0.5“本地资产备份与迁移”。
- 不改变现有搜索字段、排序、摘要、高亮、归档恢复和阅读卡片去重规则。

## 自动验收门禁

- [x] 搜索关闭时，工作区更新与流式回答不会创建全文索引。
- [x] 同一次搜索会话中，重复按 `Ctrl/⌘ + K` 复用同一份快照，不重复创建索引。
- [x] 关闭后再次打开搜索时，使用最新工作区与阅读卡片创建新快照。
- [x] 全局搜索及其 MiniSearch 依赖从 Side Panel 首屏分包移出。
- [x] 阅读卡片界面首次打开时加载；加载后仍保留挂载，由原组件完成关闭动画与焦点恢复。
- [x] 开发构建的名称、短名称和版本显示包含 `DEV`，生产构建不包含。
- [x] `package.json`、锁文件和 Manifest 版本统一为 `0.4.1`。
- [x] `npm run check`、`npm test`、`npm run build`、`npm run zip` 全部通过。
- [x] 记录优化前后的 Side Panel 首屏分包体积和仍存在的非阻塞警告。

自动验收结果：47 个测试文件、248 项测试全部通过；生产构建与 ZIP 生成成功。Side Panel 首屏脚本从 808,952 B 降至 775,296 B，减少 33,656 B（4.16%）；全局搜索分包为 27,539 B，阅读卡片分包为 6,202 B。构建仍提示既有的 500 kB 分包警告，当前主要来自 Side Panel 主消息流和 Mermaid 依赖，不阻塞本补丁版本。

候选安装包：`.output/yemai-reading-assistant-0.4.1-chrome.zip`，大小 1,274,778 B，SHA-256 为 `E323ACC1F7B976964235A29E1DEEF66BF041651AFE7810CE6004D615F4E41716`。

## 发布边界

本分支完成自动验收后先保留未提交状态供检查。只有在真实 Chrome 回归通过并获得确认后，才提交、合并到 `main`、创建 `v0.4.1` 标签并发布 ZIP；标签和 Release 不在功能验收前提前创建。

当前分支：`codex/v0.4.1-search-lifecycle`。自动验收与真实 Chrome 回归均已完成，可以提交并合并到 `main`；当前尚未创建提交、标签或 Release。
