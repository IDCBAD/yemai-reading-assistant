# Chrome 侧边栏 AI 阅读助手：产品需求与 MVP 范围

## 1. 产品目标

帮助用户在浏览网页时，以尽可能低的操作成本完成理解、追问、引用和文件问答，同时维持一个连续、可追溯的阅读会话。

MVP 主要面向产品开发者本人使用，不建设账号系统或代理后端。用户在插件中配置影刀 WorkOS Agent UUID 与对应连接凭证，插件调用所选阅读助手 Agent。

## 2. 核心产品模型

### 2.1 会话不是网页容器

一个会话代表一个阅读任务或学习主题。例如，连续阅读同一本 AI Agent 教程的多个章节时，应继续使用同一会话；只有当用户主动切换主题时，才新建会话。

### 2.2 页面是上下文来源

每个页面拥有独立的来源身份：

- 页面 ID
- 标题
- URL
- 正文哈希
- 抓取时间
- 是否已进入当前会话
- 有限页面清单（概览、标题结构和相关入口）

页面被引用时不等于每次都发送完整正文。默认首次发送有限页面清单；相同版本的后续消息只携带来源身份、新引用和新问题。Agent 信息不足时根据自身能力读取明确提供的 URL。

普通文档内的标题锚点只表示阅读位置，不创建新的页面来源；`#/` 与 `#!/` 形式的 Hash Router 地址继续按独立页面处理。当前页选区复用当前文档来源，不在同一轮重复发送相同的长 URL。

### 2.3 引用是独立对象

每段划词保留为独立引用卡片，包含引用文本和来源页面。引用可以删除，不自动触发 Agent 请求。

### 2.4 会话与 Tab 是两层结构

- 一个会话对应且只对应一个 WorkOS `conversationUuid`，负责一条连续、独立的 Agent 记忆。
- 一个工作页是一个“已打开的会话窗口”，只指向一个会话；工作页本身不是会话类型。
- 页面不是插件 Tab。用户在浏览器中切换网页时，只会把新页面作为当前会话的新上下文来源，不自动创建插件 Tab。
- `+` 是唯一的“新对话”入口：创建新的本地草稿会话并在新工作页打开；该会话第一次发送消息时才创建远端 `conversationUuid`。
- 不提供“在当前工作页替换为新会话”的第二入口，避免把新建关系和展示位置混为一谈。
- 从历史选择尚未打开的会话时，为它新增工作页；如果该会话已打开，则直接定位到已有工作页。
- 关闭插件 Tab 只关闭本地窗口，不删除本地历史、WorkOS 会话或远端消息。
- 同时最多打开 10 个工作页；达到上限后禁用新对话、分支和历史打开，并提示先关闭一个工作页。
- Tab 条支持横向滚动，切换、新建或从历史定位后，当前 Tab 必须自动滚动到可见区域。
- 工作区至少保留一个工作页；最后一个工作页不能关闭，也不会因关闭动作隐式创建新会话。

### 2.5 会话分支

- 每条已完成的 Agent 回答都可以作为分支点。
- 分支复制当前会话从开头到该回答为止的可见消息、引用和 Agent Markdown，并创建一个新的本地会话。
- 分支不复用原会话的 `conversationUuid`；第一次在分支中继续提问时懒创建新的 WorkOS 会话。
- WorkOS 暂无会话克隆接口，因此首轮请求会把分支点之前的可见记录作为结构化上下文注入。
- 分支不复制内部推理、工具参数、完整工具输出或 WorkOS 中不可见的远端记忆。
- 分支名称不通过重复拼接“· 分支”表达层级。会话保留稳定的基础标题，父会话、根会话、分支点和序号使用结构化元数据保存。
- 分支工作页显示轻量来源标记，并提供返回直接父会话的入口。
- 历史列表按直接父子关系展示主会话和多级分支，标题不通过重复拼接“· 分支”表达层级。
- 未达到 10 个工作页时，分支创建后在新工作页打开；达到上限时不创建分支，并提示先关闭一个工作页。

## 3. 目标用户路径

```text
打开网页
→ 插件在本地识别页面，但不调用 Agent
→ 用户划词
→ 侧边栏关闭时显示轻量悬浮入口
→ 点击入口打开侧边栏并加入引用
→ 侧边栏打开时，划词直接加入引用区
→ 用户输入问题并发送
→ 首次在该页面提问时附带页面正文
→ Agent 流式回复
→ 用户切换网页后继续当前会话
→ 用户需要干净任务时新建插件 Tab
→ 用户也可以从历史为已有会话打开新的工作页
```

## 4. MVP 功能范围

### 4.1 首次设置

- 用户填写全局 WorkOS Agent UUID，并选择 v1 或 v2 连接通道。
- 安装包不提供内置 Agent UUID；连接配置升级时清空旧版可能隐式写入的 UUID，要求用户重新填写自己的 Agent。
- 新安装默认选择实验性实时连接；已有设置继续保留用户选定的通道。
- Token 默认隐藏，可更新或移除；Agent UUID 明文展示并可修改。
- 实验性实时连接允许用户主动从已登录的影刀 AI WorkOS 页面导入 Access Token、User UUID 和 Organization UUID。导入只填入当前设置草稿，不自动测试、保存或发送消息。
- 设置页提供可展开、可复制的 Agent.md 推荐模板，用户把它安装到 Agent 的最高优先级人设中。
- 用户可以主动测试 Agent UUID 与连接凭证；测试中、成功和失败使用不同的颜色、图标和文字反馈。
- 更换 Agent UUID 后不复用旧 Agent 的远程会话；下一轮在新 Agent 建立会话并一次性衔接本地可见历史。

### 4.2 Side Panel

侧边栏包含：

1. 顶栏：产品身份、当前会话名称和设置入口。
2. 页面栏：页面标题、域名、上下文状态和重新读取入口。
3. 消息区：消息、引用、附件、Markdown 和代码块。
4. 输入工作台：工作页切换、新对话、历史会话、引用卡片、附件卡片、输入框、停止或发送按钮。

会话和页面管理属于输入工作台，不放在顶栏：

- `+`：新建一个插件 Tab，并在其中创建独立的本地草稿会话；最多 10 个。
- 新对话：在当前插件 Tab 中创建新的本地草稿会话，原会话保留在历史中。
- 历史：在输入框上方打开悬浮会话抽屉；选择未打开的会话后新增工作页，已打开会话则直接定位。
- 右键 Tab：关闭该会话窗口，不删除会话历史。

### 4.3 划词引用

- 侧边栏关闭时，划词后出现轻量悬浮入口。
- 用户点击入口后打开全局侧边栏并加入引用。
- 侧边栏打开时，划词直接加入输入区。
- 不因划词自动向 Agent 发送请求。
- 空白、过短和完全重复的选区不加入。
- 用户可以删除任意单条引用。

### 4.4 页面上下文

- 打开页面时只做本地准备，不调用 API。
- 打开页面后在本地准备 Page Manifest、主要正文和正文哈希，不调用 Agent。
- 首次发送默认加入 Manifest，不直接上传完整正文。
- 同一内容版本后续使用来源身份复用会话上下文。
- Agent 无法读取浏览器页面时才发送有限 Snapshot。
- 发送后保存来源、有限 Manifest 和哈希，不长期保存完整正文。
- 页面内容变化后显示“页面可能已更新”。
- 用户点击“重新读取页面”后，新版 Manifest 随下一条消息加入当前会话。
- 不支持的页面显示明确的降级说明。

### 4.5 跨页面会话

- 默认跨 URL、标签页导航延续当前会话。
- 当前页只跟随 Side Panel 所属 Chrome 窗口的活动标签页；切换到其他浏览器窗口或屏幕不会改变该 Side Panel 的页面引用。
- 新页面第一次参与提问时，作为新的来源进入当前会话。
- 用户保持在同一个插件 Tab 时，即使浏览器页面变化，也继续使用该 Tab 对应的同一个会话。
- 用户点击“新对话”时创建新的工作页和独立草稿会话，用于隔离新任务。
- 草稿会话第一次发送时才创建远端 `conversationUuid`。

### 4.6 Chat

- 用户可以直接提问，也可以带引用或附件提问。
- Agent 回复以流式方式展示。
- 流式输出只在用户停留于底部时自动跟随；用户向上滚动后暂停粘底，并提供悬浮入口返回最新内容。
- 支持 Markdown、列表、表格、链接和代码块。
- 完整的 `mermaid` 代码块在回答结束后渲染为图表；流式阶段保持源码，语法错误时回退为可复制代码。
- Agent 生成图片在消息内展示并支持大图查看；HTML、Markdown、PDF、Office 等输出文件默认使用紧凑下载卡片，不在消息流中直接嵌入 HTML 预览。
- 纯文件或纯图片回答同样视为有效完成，不要求必须存在文本正文。
- 代码块和整条 Agent 回答均支持复制；复制整条回答时保留原始 Markdown。
- 每条已完成回答支持“从此处分支”。
- 支持停止生成、失败重试和明确但克制的错误状态。
- 已有正文但运行终态异常时只显示低强调的“回答可能不完整”提示；完全无回复时才显示完整错误原因。
- 失败状态、重试、复制和分支位于同一条低强调回答操作栏。
- 不展示内部推理、Agent 配置或系统指令。工具生命周期仅展示名称、状态和耗时，不展示参数或完整输出。

### 4.7 文件

支持通过附件按钮选择：

- PDF
- Word
- TXT
- Markdown
- 常见图片

输入框支持直接粘贴剪贴板图片。粘贴只在剪贴板实际包含图片文件时接管事件，普通文本、链接和代码仍沿用浏览器原生粘贴行为。通用剪贴板文件名会转为可区分的“粘贴图片 N.扩展名”，从系统文件管理器复制的有效原文件名则保留。

图片加入输入框后显示即时缩略图，上传状态覆盖在缩略图上；上传成功后状态降级为文字，右侧只保留删除操作。已发送图片以带真实缩略图的行内附件 Token 与问题文字共同排版；鼠标悬浮或键盘聚焦时显示保持完整比例的锚定预览，移开后自动关闭，点击后仍可在侧边栏内查看沉浸式大图。图片加载失败时降级为文件附件。

附件具有等待上传、上传中、上传成功和上传失败四种状态。上传失败的附件不能随消息发送。

### 4.8 本地历史

本地保存：

- 会话列表及本地标题
- `conversationUuid`
- 用户和 Agent 消息
- Agent 输出产物的文件名、类型、状态与远程 HTTPS 地址，不保存文件二进制
- 引用和附件元数据
- 已发送页面的 URL、标题、哈希和发送时间
- 当前会话和当前 Tab
- 已打开 Tab 与会话的绑定关系
- 各会话的未发送输入、引用和附件草稿

“清空历史”只清除插件本地会话和消息，不删除 Token、WorkOS 会话或远端上传文件。操作前必须清楚说明此边界。

历史抽屉提供“会话 / 归档”两个本地视图。归档仅隐藏主历史列表中的会话，不删除消息、引用、页面来源或远端会话；归档会话可以恢复。为避免状态歧义，正在任意插件 Tab 中打开的会话不能归档，用户需要先关闭对应 Tab。

永久删除仅出现在归档视图，支持删除单条归档历史和清空全部已归档历史。删除不会级联移除仍然存在的分支会话，也不会调用 WorkOS API；确认文案必须说明 WorkOS 后台会话与已上传文件仍然保留。

设置页显示“本地历史占用空间”，分别给出 IndexedDB 历史估算、`chrome.storage.local` 配置占用和浏览器估算可用空间。历史与连接设置分开统计；浏览器配额是动态估算值，不展示为固定 10 MiB 精确上限。

关闭或重新打开 Side Panel 后必须恢复上述状态。若关闭时仍在流式生成，重新打开后将该消息和未完成工具标记为“已停止”；MVP 不尝试恢复已经断开的 SSE。

### 4.9 全局搜索

- 顶栏提供全局搜索入口，并支持 `Ctrl/⌘ + K` 从侧边栏任意位置即时打开。
- 搜索范围包括会话标题、用户提问、Agent 回答、页面标题与 URL、引用文本、附件和 Agent 产物文件名。
- 中文搜索不依赖空格分词；英文搜索支持前缀和克制的拼写容错。
- 空查询展示最近会话；有查询时按标题、用户提问、Agent 回答、页面和文件名的顺序加权排序。
- 每条结果展示会话标题、匹配摘要、内容类型、时间和归档状态；不得展示内部推理、工具参数或未投影的原始事件。
- 选择消息结果后打开对应工作页，并精确定位到用户提问或 Agent 回答，短暂显示定位反馈。
- 归档会话仍可检索；在工作页未达到上限时，打开搜索结果会一次性恢复并打开该会话。
- 已打开 10 个工作页时，不恢复或打开新的搜索结果，并明确提示先关闭一个工作页。

### 4.10 收藏卡片

- 已完成且包含正文或产物的 Agent 回答可以收藏为“完整回答”；流式回答不能收藏。
- 用户可以划选已完成回答中的文字，一键收藏为“回答片段”，同时保留“引用追问”动作；同一来源消息和相同规范化正文不得产生重复片段。
- 收藏卡片保存类型、用户可见正文快照、有限来源信息，以及完整回答包含的 Agent 产物元数据；不保存内部推理、工具参数或文件二进制。
- 收藏卡片是独立知识资产，不属于会话 `WorkspaceState`。原会话删除后卡片仍可阅读，但“回到原对话”明确变为不可用。
- 顶栏提供独立收藏入口；列表区分完整回答与回答片段，并展示标题、摘要、首个来源和收藏时间；详情展示正文、来源和可用产物。
- 原会话仍存在时，“回到原对话”打开或激活对应工作页并定位到来源消息；归档恢复与打开必须保持原子性，工作页满额时不产生半恢复状态。
- 全局搜索覆盖卡片标题、正文、来源和产物文件名。同一来源回答已收藏且卡片命中时，隐藏重复的原消息结果。
- 取消收藏只删除收藏卡片，不修改原消息；清空会话历史保留收藏卡片，并在确认文案中明确说明。
- 收藏不会调用 Agent，也不会创建或修改认知 Markdown；认知形成以后从用户主动选择的收藏卡片发起。

## 5. 目标网页

### 5.1 普通文章与文档站

完整支持语义化网页，包括官网文章、博客、教程和技术文档。正文提取需保留标题层级、段落、列表、引用和代码块。

### 5.2 X / Twitter

产品目标优先覆盖：

- 用户划词
- 单条推文详情页
- 可识别的线程内容

不承诺完整读取首页时间线或无限滚动信息流。

当前实现尚无 X / Twitter 专用抽取器，详情页仍使用通用网页抽取与降级策略。现阶段要获得精确内容，应优先使用普通划词或智能框选；上述详情页与线程能力仍是目标而非已完成承诺。

### 5.3 浏览器受限页面

`chrome://` 页面、Chrome Web Store、内置 PDF 阅读器等无法正常注入内容脚本的页面，需要显示不支持说明。PDF 内容通过文件上传能力处理。

## 6. 明确不做

- WorkOS 远端会话列表同步
- 远端消息拉取、重命名或删除
- 模型切换、技能选择和知识库配置
- 账号系统和代理后端
- 语音输入
- 自动总结或自动拆分长会话
- 跨设备同步
- 完整抓取 X 首页时间线
- 关闭侧边栏后恢复未完成的流式回答
- 执行网页正文中的任务或指令

## 7. 原型验收标准

原型阶段使用模拟数据，应能验证：

- 在历史会话之间切换，并通过唯一的“新对话”入口新建本地草稿会话。
- 将未打开的历史会话归档并恢复，已打开会话的归档按钮明确禁用。
- 在归档视图永久删除单条历史或清空全部归档，确认后仅影响本地记录。
- 从回答创建新会话分支，并在分支中保留该回答之前的完整可见上下文。
- 新建、切换和右键关闭多个会话工作页，每个工作页只打开一条会话。
- 达到 10 个 Tab 后不能继续新增；当前 Tab 始终可见，Tab 条可横向滚动。
- 从历史为未打开会话新增工作页；选择已打开会话时直接定位到已有工作页。
- 不同 Tab 的消息、草稿和 Agent 记忆互不混用。
- 展示当前页面及“未读取、已读取、已变化”状态。
- 添加和删除多条独立引用。
- 添加和删除模拟附件，展示上传状态。
- 输入消息并观看模拟流式回复。
- 停止模拟生成。
- 展示 Markdown、代码块、错误和空状态。
- 清空本地模拟历史前展示边界提示。
- 设置页显示历史占用、全部本地占用和配额进度。
- 使用顶栏入口或 `Ctrl/⌘ + K` 打开全局搜索，支持方向键选择、回车打开和 Escape 关闭。
- 使用中文和英文关键词分别命中会话标题、提问、回答、网页与文件名，并显示匹配摘要。
- 从搜索结果定位到具体消息；打开归档结果时自动恢复，工作页满额时不产生半恢复状态。
