# 百度查词接入

2026-10-23。开发分支：`codex/baidu-word-translation`。这是正式代码的基础接入，尚不等于语境词义质量验收，也没有发布或推送。

## 使用

构建目录为 `.output/chrome-mv3`。重新加载扩展，并刷新需要查词的网页。在页脉设置的“查词与翻译”填写百度 APPID 与 API Key，选择默认服务并主动开启远程请求。设置独立保存，不受 WorkOS 连接保存影响。默认 Auto，但远程开关默认关闭，避免在用户未配置时产生收费请求。

网页选中英语单词或短语后点击“查词”，不需要先开启辅助阅读。浮窗使用420px宽度并限制在视口内；根据原选词区域合成背景，适配浅、深、暖色页面。发音复用浏览器英语语音，IPA与常见词义复用打包词库。

## 回答与收藏的主动翻译（2026-10-25）

网页查词、回答中的选词/选句翻译、收藏卡片中的手动参考翻译共用同一份服务配置。回答支持点击翻译及双Ctrl；选文最多5000字符，段落只发送所选部分，单词可附带有限原句。普通文本的Auto走机器翻译；网页带语境查词的Auto继续走大模型。明确指定大模型/机器翻译但配置不可用时显示错误，不静默切成浏览器。

本地词典模式或尚未开通百度的Auto，在侧边栏主动翻译时仍使用浏览器本地翻译。预先读取不含凭据的服务偏好，本地Translator创建直接发生在点击中。关闭旧本地翻译开关不影响已配置的百度主动翻译。

所有主动远程请求使用同一个后台runtime，因此复用前述文本缓存、限流和用量估算。新增文本消息只允许来自扩展自身的sidepanel.html，其他扩展页面和网页不能使用此通用文本入口。原网页查词权限保持不变。

打开收藏卡片时的自动补全仍是内置词典与已就绪的浏览器本地翻译，不触发远程服务。只有主动点击翻译才发送所选字段。译文确认保存保留browser/baidu来源；用户改写或清空仍按手动内容处理，保留字段快照冲突检查。

关闭、换选区、换卡、换服务后废弃迟到结果；回答的单词请求结束后，先检查是否仍有效，再决定是否提交原句请求。

验证：本轮10个相关测试文件124项通过，TypeScript与生产构建通过。`scripts/verify-unified-translation.mjs` 使用生产React组件及合成服务，验证远程不受旧本地开关阻挡、快捷键、选文范围、关闭/切服务、打开收藏不联网、手动原句翻译和实际来源保存。没有用真实Key消耗百度额度。

## 请求与数据

- `src/shared/wordTranslation.ts` 定义服务、配置、结果和本机用量。
- `src/services/baiduTranslation.ts` 只请求官方固定 HTTPS 地址 `https://fanyi-api.baidu.com/ait/api/aiTextTranslate`，使用 Bearer Key 与 APPID。禁止重定向、限制响应大小、强超时，错误采用安全固定提示。
- `src/background/wordTranslation.ts` 负责路由、串行限流、并发合并和30分钟/100条内存缓存。Auto 在有原句时选择 llm，无原句时选择 nmt；未配置时使用本地词典。手动指定服务失败不会偷偷切到其他收费服务。
- llm 查询单词时通过 `reference` 提供当前原句；原句翻译另发请求。语境、服务、凭据变化会影响缓存。最多两次请求，没有自动重试。用量为本机提交源字符估算，不是百度余额。
- 2026-10-25 优化：成功译文另按实际模型、原文、翻译指令缓存30分钟（最多200条），相同原句的在途请求也会合并。因此同一句话中换查其他单词，不重复翻译整句；部分失败后手动重试也复用已成功的单词译文。llm 的语境指令参与缓存键，换语境不混用词义。凭据变更或停用清空缓存；扩展后台重启也会失去这些内存缓存，不宣称持久保存。仅实际发出的请求增加本机用量估算。
- 每次请求真正发出前重新检查配置。停用或清除Key后，已发出的请求可能完成，但未发出的后续原句请求会停止；旧结果不会继续写入缓存或交给界面。
- 密钥只存于扩展可信 local storage，内容脚本只接收服务偏好和翻译结果；密钥不放源码、构建包、网页DOM、日志或知识备份。
- 收藏保持主动操作，并将实际释义、原句及译文保留为 `dictionary` 或 `baidu` 来源。备份导入导出支持新增来源，手动修改/清空仍受原规则保护。

## 已验证与限制

实际调用已成功验证 nmt 与 llm，单次样例约3.8–4.7秒。对于 `complete` / “at least one complete MPEG frame for MP3”，两者均返回“完成”；附加reference、尝试NMT标签保留也没有纠正这个样例。接口连通不能据此称词义准确性已解决。

当前对语境词译文只做长度/换行及整句误返检查，不是语义判定。界面标“结合原句翻译”，不应视为权威词典判断。原型第二条例句尚未有可靠来源，因此正式结果只展示实际捕获原句与真实译文；支持例句数组，后续有合适词典数据后再补齐。没有把人工示例作为真实API返回。

页面先显示本地结果，远程结果完成后补齐；当前不是百度逐token流式输出。关闭浮窗阻止界面更新；停止尚未发送的远程后续请求请在设置停用百度。
