# 页脉 v0.6.0

这是继公开版 v0.2.0 后的累计更新。页脉现在不仅能围绕网页与 AI 连续对话，也能把真正值得保留的完整回答或结论片段沉淀为独立收藏。

## 这次更新

- 完整回答和划选的回答片段都可以一键收藏，并保留原始对话与网页来源。
- 收藏页升级为可循环浏览的知识卡片河流，支持滚轮、拖拽和键盘浏览。
- 卡片拥有独立阅读层；关闭详情后会回到原卡片位置。
- 收藏页可以直接搜索，并在“收藏 / 全部”范围之间切换。
- 加入本地历史实体化、全文搜索、阅读卡片、备份迁移和 Markdown 导出等 v0.3～v0.5 累计能力。
- 优化长文本输入、Agent 工作状态反馈、卡片正文换行和窄 Side Panel 阅读清晰度。
- 修复来源 URL 路径造成的收藏搜索误命中，以及卡片空白、无法打开、滚轮失效和返回后位置跳动等问题。

## 产品方向调整

页脉不再让 Agent 在普通对话中自动判断并写入“个人认知”。当前路径是：先由用户收藏完整回答或划选片段，未来再从主动选择的收藏卡片形成认知。已有的独立 Markdown 目录连接能力继续保留，收藏本身不会调用 Agent，也不会修改本地目录。

## 安装

1. 下载 `yemai-reading-assistant-0.6.0-chrome.zip`。
2. 解压到固定文件夹。
3. 打开 `chrome://extensions` 并启用“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。
5. 打开页脉，在“连接与隐私”中填写自己的 WorkOS Agent UUID 和连接凭证。

安装包不包含默认 Agent UUID、Token、仓库源码、测试文件或项目文档。
