# v0.4 验收记录

## 范围

v0.4 将高价值 Agent 回答沉淀为独立阅读卡片，包含 Dexie v2 持久化、收藏入口、卡片列表与详情、原对话回跳及全局搜索整合。

## 自动验收

- [x] TypeScript 无类型错误：`npm run check`。
- [x] 全量单元测试通过：46 个测试文件、246 个测试。
- [x] Chrome Manifest V3 生产构建通过：`npm run build`。
- [x] Dexie v1 升级到 v2 后原有工作区实体不丢失，并可写入 `readingCards` 表。
- [x] 同一回答重复收藏使用稳定主键，不产生重复卡片。
- [x] 取消收藏只删除卡片，不修改来源消息。
- [x] 卡片保存回答 Markdown、有限来源和产物元数据，不保存文件二进制。
- [x] 原会话删除后卡片快照仍可阅读，来源跳转明确不可用。
- [x] 归档来源恢复与工作页打开是同一原子变换；工作页满额时不产生半恢复状态。
- [x] 全局搜索覆盖卡片正文，并抑制同一来源消息的重复结果。

## 真实侧边栏验收

- [x] 已完成的 Agent 回答显示低视觉权重的收藏按钮；收藏后图标填充、轻微缩放，并保留 `aria-pressed` 状态反馈。
- [x] 收藏时的小卡片在 420ms 内飞向右上角入口，入口同步显示短暂 `+1`；键盘操作不产生位移动画，静态状态仍更新。
- [x] 顶栏可以打开从入口下方向左展开的阅读卡片抽屉；列表标题、摘要、来源、时间和空状态可读。
- [x] 阅读卡片关闭按钮位于头部操作层，数量徽标样式不会再误作用于按钮外层。
- [x] 来源使用 Chrome `_favicon` 识别真实站点图标，加载失败时回退为站点首字母。
- [x] 收藏确认与抽屉开合仅使用 transform / opacity 等轻量过渡；系统启用减少动态效果后，飞入效果隐藏，填充收藏状态仍保留。
- [x] Chromium 真实渲染中，卡片详情正确渲染 Markdown 与来源；Escape 先返回列表、再次按下关闭抽屉，并将焦点恢复到顶栏入口。
- [x] 取消收藏后回答按钮和卡片列表同步更新；重新打开 Side Panel 后状态保持。
- [x] 原会话存在时可以返回并定位消息；原会话删除后卡片仍能阅读。
- [x] 搜索阅读卡片时打开卡片详情，不受 10 个工作页上限影响。
- [x] 清空会话历史不会删除阅读卡片，确认文案明确说明该边界。
- [x] 300px 窄侧边栏中，顶栏、卡片列表与详情不横向溢出（`documentWidth = bodyWidth = 300px`）。
