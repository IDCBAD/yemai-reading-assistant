# 划词收藏与单词卡片

本轮从已确认的卡片册原型进入正式组件实现：阅读时独立收藏，之后听发音、读真实原句、翻看词卡。不增加复习任务、填空或打卡。

## 使用方式

- 网页中划选英语单词或常见短语，选择「收藏单词」。收藏成功后继续阅读，不自动打开侧边栏，也不创建对话。
- 开启单词收藏时，可收藏的词语会显示「收藏单词 / 引用」两种操作，不自动加入提问；长文本保留原有引用方式。
- 页脉回答中的划词同样支持收藏单词；先翻译时，可以收藏单词和已经取得的译文。
- 顶栏「收藏」内使用相同位置的「问答收藏 / 单词收藏」标签直接切换。问答保留瀑布流、列表和导出，单词册提供目录搜索、逐张翻看、发音、原句朗读、释义编辑、移除与五秒撤销。
- 设置中的「划词收藏单词」控制网页与回答的单词收藏入口。「回答内划词翻译」只控制页脉回答内的本地翻译，不修改沉浸式翻译的设置。

## 内容来源

收藏始终先保存所选词语和可取得的原句。原句依据实际选区位置提取，重复出现的词不会被任意定位到句首；跨段落或无法确认上下文时只保留单词，不拼造例句。输入控件、可编辑区域和代码中的词语不会触发收藏。

网页内容与回答内容保留不同来源。回答中的词卡不冒充文章原句；会话删除后，已保存的词和原句仍然保留。

沉浸式翻译继续负责原有查词体验。本版不读取它的浮窗内部结构、不调用它的账户或私有接口。公开[浏览器插件集成说明](https://immersivetranslate.com/zh-Hans/docs/browserExtensionIntegration/)介绍的是合作集成，本轮没有确认可供另一扩展直接读取词义的公开接口。

打开词卡后自动补齐缺少的词义和原句中文，两项独立加载、独立保存，不阻塞打开和翻卡；旧卡片也适用。词义优先精确查询内置 ECDICT 英汉词库；缺词时再尝试浏览器本地英译中，参考译文显示「译」标记。词库采用固定版本 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`，筛选常用及考试词条、常用频率词条和有明确变形关联的原始记录，含 80,137 条、约 5.18 MB，按首字母拆分，按需加载。释义保留原始前两行，不生成词性或推断词典原形；社区词库的释义不表示已按当前语境消歧。重建脚本、筛选方式、来源和完整许可见 `scripts/update-word-meaning-dictionary.py` 与 `public/dictionaries/ECDICT-README.md`。

原句中文通过 Chrome 的本地 Translator 取得，翻译完整捕获句子。语言包尚未准备时显示「启用翻译」，用户点一次后再补充；浏览器不支持时明确提示，仍可手动填写。下载按实际进度显示，75 秒无进展允许重试；单次自动翻译最多等待 30 秒，失败保留重试入口。不读取沉浸式翻译内部内容，不调用 WorkOS，不把单词或原句发送给外部翻译接口。

两处中文均可编辑。自动补充只填写空白内容，不覆盖已有释义或手动清空。显式保存只检查被编辑字段是否发生变化，因此另一字段的自动补充不影响保存；本字段确实被改过时拒绝覆盖并保留编辑草稿。手动清空后仍允许用户主动翻译并确认保存。异步结果按词卡 ID 和来源标识检查，不重新创建已删除的卡片。

音标使用内置的美式 IPA 词库，版本固定为 ipa-dict `43c3570eb3553bdd19fccd2bd0091534889af023` 的 `en_US.txt`。首次打开词卡时加载本地资源，其后复用；运行时缓存原文并精确查找对应行，避免打开时构造整个词库的 Map；只精确查找词文本，不推断原形、不生成音标，缺词时不显示音标。多种读法原样保留；词库和完整许可位于 `public/dictionaries/`，不需要新增网络权限，不向外部发送单词或原句。

打开单词册或显式翻卡默认自动读词一次，右上角可关闭并保存设置。输入搜索时不连读，选择搜索结果后正常自动读词。发音采用浏览器英语语音，原句按需朗读；切卡、关闭、编辑、静音和隐藏页面会停止旧语音。界面仅在浏览器真实 `onstart` 后显示播放状态；未开始就结束时，用默认英语声音重试一次，再失败明确提示，不将调用成功视为已发声。

问答和单词共用一个持续挂载的收藏外壳和顶部标签。打开统一使用 180ms、12px 位移与淡入；分类切换只替换内容，不重复播放入场。首次模块尚未准备好时保留外壳；已打开时切换到尚未加载的分类，先保留原内容，准备好再切换。问答保留列表模式和阅读位置，单词保留当前词卡；隐藏的词卡不继续发音或启动补充。键盘打开与减少动态效果设置不播放入场过渡。

单词导航采用已确认的 A 方案：底部只保留固定高度的上一张、页码与下一张，不再平铺全部词条。点击页码从底部展开目录；目录包含单词、释义或原句摘要，可搜索单词、释义、原句和来源。目录独立滚动，选词后收起并返回对应卡片；搜索不会改变背后的词卡，关闭目录清空临时搜索。单词少时也使用相同入口，不因数量变化切换布局。

目录箭头使用固定 14×14 的 SVG，与页码居中对齐，展开时转向上方；左右翻页箭头同样采用 SVG，不依赖字符字体或基线。鼠标展开使用 180ms 轻微上移；键盘及减少动态效果设置不播放进入动画。Escape 先关闭目录、焦点回到页码，Tab 保持在目录内，上下键移动目录项焦点。编辑或保存期间禁用翻页和目录；查看目录时停止语音并暂停自动朗读，直接收起不补播，选另一张卡片恢复正常自动读词。

词卡删除重复标题、标语、装饰编号、来源类型和缺释义说明；原句和来源链接保留。网页划词的收藏与引用共用一个外壳和分隔线，保存中、成功、失败均原位反馈。

## 保存与迁移

- 单词独立保存于本机 IndexedDB；Dexie v5 新增 `wordCards`，v4 及更早会话和问答收藏保留。
- 同词、同来源、同原句重复收藏不会新增卡片；另一处原句可单独保存。规范化只处理大小写、空白和撇号，不推断词典原形。
- 保存、编辑、删除、撤销都由后台处理。后台写入成功才反馈成功；没有打开侧边栏时，刷新通知失败不影响保存结果。
- 单词写入与已有备份导入使用同一执行顺序；导入期间拒绝新的单词修改。
- 新导出使用 `yemai-backup` v2，包含词卡、词义及来源、可选原句译文及来源和数量。新增字段可选，不要求新的数据库索引或结构升级。仍接受旧 v1：合并保留现有词卡，替换则清空旧词卡；确认界面显示影响数量。
- v2 缺少词卡列表、数量不符、重复记录、无效日期等均在写入前拒绝。合并和替换失败会回滚。
- 清空会话历史仍保留问答收藏和单词卡片，不改变原操作含义。
