# v0.3 验收记录

## 范围

v0.3 包含两部分：

- v0.3a：IndexedDB 实体化存储、旧快照一次性迁移、增量保存和本地占用统计。
- v0.3b：全局全文搜索、命令面板、归档结果恢复、工作页打开和消息精确定位。

## 自动验收

- [x] TypeScript 无类型错误：`npm run check`。
- [x] 全量单元测试通过：43 个测试文件、228 个测试。
- [x] Chrome Manifest V3 生产构建通过：`npm run build`。
- [x] 旧 v1～v6 快照迁移后会话、消息、来源、产物和工作页绑定无丢失。
- [x] 中断迁移可以从 `data-written` 标记恢复，完成迁移不会重复导入。
- [x] 80 个会话、2,000 条消息、240 个来源和 960 个产物可完整迁移与重建。
- [x] 修改单条消息只写入一个实体，不重写其余 3,279 个实体。
- [x] 2,000 条消息可在交互预算内完成索引并定位唯一中文关键词。
- [x] 搜索覆盖标题、用户正文、Agent 正文、页面元数据和产物文件名。
- [x] 日期和带连接符标识符必须在单个字段中完整出现，不能跨字段拼成假阳性结果。
- [x] 中文使用词级分段；“人类”不会误命中“达人类型”，省略助词的自然语言查询仍可命中。
- [x] 搜索摘要围绕实际命中词截取，打开结果后滚动到消息内部首个命中词；消息轮廓和关键词高亮约 2.8 秒后消失。
- [x] 归档结果保持可搜索，选择时恢复与打开是同一原子工作区变换。
- [x] 工作页满额时不恢复归档结果，不产生半完成状态。
- [x] 键盘选择支持上下循环、跳过不可打开结果；匹配高亮不插入 HTML。

## 提交前最后一轮真实侧边栏验收

以下项目需要在 Chrome 重新加载当前 `.output/chrome-mv3` 后操作真实 Side Panel。浏览器自动化不能接管 `chrome://extensions` 或 Side Panel，这是 Chrome 的安全边界；完成这些项目之前不提交。

- [ ] 顶栏搜索按钮和 `Ctrl/⌘ + K` 都能打开命令面板，输入框立即获得焦点。
- [ ] 空查询展示最近会话；Escape、遮罩点击均能关闭。
- [ ] 中文关键词能命中旧会话中的提问或回答，标题、摘要、时间和类型可读。
- [ ] 方向键切换结果，Enter 打开；鼠标悬浮和点击行为一致。
- [ ] 消息结果打开正确工作页并滚动到正确用户/Agent 消息，定位反馈清晰且不改变内容布局。
- [ ] 归档结果显示“已归档”，打开后从归档列表恢复并定位到命中消息。
- [ ] 工作页达到 10 个时，新结果禁用并提示先关闭工作页；归档状态不被意外改变。
- [ ] 300px 左右窄侧边栏中，输入框、结果标题、摘要和底部快捷键不溢出。
- [ ] 重新关闭并打开 Side Panel 后，历史和恢复状态仍然存在。
