## 使用方式

- 点击图片进入预览；支持缩放按钮、滚轮缩放、拖动、原始尺寸和适应窗口。双击切换原始尺寸与适应窗口，画布支持加减键缩放、方向键移动、`0` 恢复适应窗口。
- 文件卡片提供“预览”和“下载”，点击文件名或“预览”直接打开独立预览标签页，不在侧边栏里先显示预览弹窗；新标签页打开失败时在卡片区域提示重试。
- 独立标签页提供“进入全屏 / 退出全屏”，浏览器退出全屏时按钮同步恢复；全屏切换不会重新加载网页。图片仍使用原有侧边栏查看器，并保留展开查看入口；图片预览关闭后恢复到原来的卡片焦点。
- 输入图片复用同一个图片查看器；收藏卡片的产物链接本轮保留原有打开方式。
- 工具栏采用浅灰底与无边框图标操作；文档查看方式使用下划线文字页签。图片底部将缩放比例与尺寸切换分组。文件卡片保留文字“预览”入口，下载使用图标；各图标有操作名称，键盘焦点可见，触屏扩大点击区域。只有悬停和按下反馈，视图切换与缩放立即响应。

## 格式和限制

| 格式 | 展示 | 限制 |
| --- | --- | --- |
| 图片 | 默认适应窗口，显示实际缩放比例 | 100% 以读取到的图片像素尺寸为准；缩放最大 800% |
| Markdown | 正文、原文、表格、代码和 Mermaid | 超过 200,000 字符时分段显示原文；相对链接和图片按文件地址解析 |
| HTML | 交互页面、源码 | 默认支持文件内自带的脚本和样式；交互运行不加载外部脚本、样式、图片、字体或接口，不提交表单；外部 HTTPS 链接先显示目标域名供用户点击 |
| Excel | XLS / XLSX / XLSM 的可见工作表、基本数字格式 | 不运行宏或重新计算公式；优先显示已有计算结果；不还原图表和复杂排版 |
| CSV | 表格、原文 | 保留前导零、引用逗号、多行文本和看起来像公式的字符串 |
| JSON | 格式化、原文、语法高亮 | 格式有误时保留原文；格式化仅影响展示，复制仍保留原始内容 |
| TXT | 文本、复制 | 不编辑原文件 |
| 源码 | Python、JavaScript、TypeScript、Shell 等已有语言的行号、语法高亮、原文复制 | 依据文件扩展名识别；只显示文本，不运行代码；超过 20,000 字符分段显示且停止高亮 |

- 文本文件最多读取 2 MiB，Excel / CSV 最多读取 10 MiB；同时检查声明大小和实际流式读取大小。
- 读取和解析总时间最多 20 秒。关闭预览取消请求并停止表格后台线程。
- 表格每个工作表预览前 2,000 行、100 列以内的数据，每次展示 100 行，通过上一批 / 下一批切换。截断时明确提示下载完整文件。
- 文本原文每次追加 20,000 字符，长文本不做语法高亮。
- 源码、JSON 和 HTML 源码视图显示行号。长行保持原始布局并支持横向滚动，行号栏固定在左侧；空行和文件末尾换行计入行号，继续显示后连续编号。复制按钮保留原文，不包含行号。
- 文件必须是无内嵌用户名或密码的 HTTPS 地址；读取受现有扩展 `host_permissions` 和 `connect-src` 限制。不会向文件地址附带 WorkOS 连接凭据。
- 本轮没有扩大扩展域名权限。其他文件域名、失效链接、密码文件和不支持的编码应回退到下载。

## HTML 交互运行

- 通过 WXT sandbox 入口生成独立运行页面，再在不含同源权限的 iframe 中展示当前 HTML。普通扩展页面的脚本策略保持不变，运行页面不能读取扩展 API、父页面 DOM 或扩展存储；不传入 WorkOS 登录凭据或会话数据。
- 页面保留原有内联脚本、事件、表单控件、SVG 和 CSS。默认禁止外部资源与嵌套页面，因此需要 CDN、多文件或联网接口的 HTML 不在本版支持范围内；HTML 自己没有交互逻辑时不会自动获得交互。
- 复制只提供有长度限制的写入功能，需要预览获得焦点并有近期用户操作；不提供读取剪贴板、访问扩展存储或代发网络请求的能力。消息校验发送窗口、隔离来源和本次运行编号。页面仍可使用原有浏览器复制回退。
- 外部 HTTPS 链接在宿主预览中显示目标域名，由用户再次点击后在浏览器中打开；相对路径、多文件导航、自动弹窗和表单提交不支持。
- 原页面的 `localStorage` 不可用，评论、标注等是否可继续运行取决于页面自己的回退处理。提供的 Blender 样例可在当前打开期间使用。关闭、刷新标签页或新开预览会创建新的运行实例，不保存填写内容；仅切换源码或全屏会保留当前实例。
- 正常展示时没有模式说明或额外工具栏，不提供静态预览切换。运行环境未成功打开时才显示错误和重试入口；需要主动重置时可刷新浏览器标签页。
- 权限隔离不等于性能隔离，不保证任意死循环或高负载脚本不会影响浏览器。尚未实现任意网页兼容、跨次恢复或后台运行网页。

## 临时预览记录

独立标签页地址只包含随机编号。扩展用 `chrome.storage.session` 传递产物元数据，读取后移除传递记录；标签页自己的 `sessionStorage` 支持刷新，记录有效期一小时，不保存文件二进制。修改预览编号会重新加载对应文件。开发原型用本地模拟数据，不访问真实 WorkOS 文件。
