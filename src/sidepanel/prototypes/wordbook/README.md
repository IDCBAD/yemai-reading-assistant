# 单词收藏交互原型

用于判断：阅读时独立收藏单词是否顺手，以及卡片册和词语集哪种形式更愿意打开。仅为前端体验原型，不接入正式扩展数据库、WorkOS、词典服务或沉浸式翻译插件。

在项目根目录运行：

```powershell
node scripts/serve-wordbook-prototype.mjs
```

- 卡片册：http://127.0.0.1:4186/?variant=A
- 词语集：http://127.0.0.1:4186/?variant=B
- 底部切换器可随时切换两种形式，已收藏内容不受切换影响。

## 体验路径

1. 在文章中点选或划选 unpredictable、navigates、workflows、adapt、recover、goal。
2. 翻译浮窗用模拟内容表示沉浸式翻译已有的体验；收藏按钮是独立入口。
3. 关闭「翻译浮窗」后仍能收藏。设置里还能独立关闭「页脉收藏入口」。这些开关不会修改沉浸式翻译插件的真实设置。
4. 收藏后在右侧查看单词、词性、音标、释义和文章原句；可以听单词、听原句、展开原句译文、翻看其他词卡。
5. 可以搜索、移除收藏并撤销。窄窗口通过顶部按钮切换文章和收藏，收藏后自动返回收藏页。

原型预置 adapt、navigate、recover 三个收藏。刷新或点击「重置演示」会恢复这三个词，不保留真实收藏。其他词没有预置释义时会提示，不会伪造查询结果。

## 内容和发音边界

文章来源：https://browser-use.com/posts/browser-agents 。开篇采用用户截图中的文章文字；TL;DR 是用于原型的改写摘要，已在页面注明。释义、音标和句子中文翻译是手工准备的演示数据，不表示实际词典服务质量。卡片保存的英语例句来自开篇原句；navigates 和 workflows 的词条展示为原形。

发音使用浏览器 SpeechSynthesis 英语语音，不使用付费服务。声音和可用性取决于本机浏览器及语音支持；未启动或失败时会提示。浏览器检查已观察到英语语音可用及朗读结束事件，没有对音色和听感作人工验收。
